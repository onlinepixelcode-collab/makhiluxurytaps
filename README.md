# Makhi Luxury Taps — website demo

A multipage luxury e-commerce demo for Makhi Luxury Taps, built by Pixel Code.

- `build/` — Python generator (`python3 build/build.py`)
- `site/` — the built static site (served on the `gh-pages` branch)

Product names, prices and photos come from makhiluxurytaps.co.za. Ordering is disabled in this demo.
